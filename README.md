# system-design-interview
홍익대학교 2026-2 대규모 시스템 설계 스터디입니다.

- [스터디 책](http://product.kyobobook.co.kr/detail/S000001033116)

## 📆 기간

- 일정 : 2026. 09. 8(화) ~ 2026.11.17(화) / 총 8주(시험기간 제외)
- 매주 화요일 18시에 대면으로 진행합니다.

## 🖐 모집 인원 및 장수

- 총 7명
- 총 15장을 1주일에 2장씩 진행합니다. 
    - 1장은 내용이 많아 단독으로 진행합니다.
    - 즉, 총 16장을 매주 2장씩 진행하여 8주 동안 스터디합니다.
    

- 16장 (마지막 장)은 제외합니다.

## 📜 진행방식

- 발표자는 매주 화요일 00시 전에 발표자료를 PR 로 올립니다.
- 그 외 인원은 월요일 00시 전에 각 장마다 질문 혹은 중요하다고 생각되는 부분을 Issue 로 남겨주세요.
- Issue 작성 이후 Pr로 올려 승인을 대기합니다.
- 발표에 대한 내용은 아래를 참고해주세요.
- 발표가 모두 끝나면 발표자 중심으로 준비한 질문 기반 디펜스를 진행합니다.
- 디펜스 이후 전체 인원이 간단한 회고를 진행합니다.

## 🖥 발표

- 발표는 일주일에 2챕터씩 진행하며, 각 챕터 마다 발표자가 배정이 됩니다.
- 발표자는 발표자료를 만드는 작업을 진행합니다.
- 시작 시 발표자는 발표자료를 이용해 발표를 진행합니다.
- 발표자는 그 주에 올라온 Issue 를 리뷰하며 다 같이 논의합니다.

## 📚 Github 저장소

- PR에 대한 머지는 직접 운영진이 할 예정입니다.
- 발표자료의 파일명은 아래와 같이 해주세요.
- 본인의 영문 이름에 맞는 브랜치를 만들고 다음의 형식으로 패키징해 스터디 내용을 올려주세요.
- 스터디 내용은 마크다운 형식의 파일로 올려주세요.

```text
study
├── 본인의 영문이름(dir)
│   ├── 2주차
│   │   └── [2주차] 2장_강상준.md
│   │   └── [2주차] 3장_강상준.md
│   │
```

```java
[X주차]_X장_이름
```

- PR 은 아래와 같이 제목을 작성해주세요.
```java
[X주차]_본인이름
```

- Issue 는 아래와 같이 제목을 작성해주세요.
  - 2장씩 진행하므로 주차별 이슈 안에 각 장의 내용을 분리해서 작성해주세요.
```java
[X주차]_본인이름
```

## 👨‍👩‍👧‍👦 회고

- 1주일 동안 책을 읽으면서 느낀점, 발표를 보고 느낀점 들을 자유롭게 이야기 해주시면 됩니다.
- 자유롭게 각자 하고 싶은 말을 하면 되니 부담 가지실 필요는 없습니다.
